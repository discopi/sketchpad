# Sketchpad

A simple sketching app for my tablet, inspired by Concepts. It runs entirely in the browser and works offline once installed.

Live at https://sketch.pieheartstudio.co.uk

- Pen, background (fill) and shadow layers, each with their own colour group
- Saved palettes, each with its own font
- Select, nudge, eraser and text tools
- PNG export, plus backup and restore

Drawings, palettes and fonts are stored on the device only. Nothing is sent to a server.
